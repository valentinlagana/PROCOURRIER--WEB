# Pro Courrier — Web oficial

Sitio web institucional de Pro Courrier SRL, Partner Certificado de Mercado Libre.

- Archivo principal: `index.html` (contiene todo: estilos, imágenes, video y fuentes)
- Hosting: Vercel
- Dominio: procourier.com.ar

## Cómo actualizar la web

1. Subir el nuevo `index.html` a este repositorio (Add file → Upload files → Commit changes).
2. Vercel detecta el commit y publica automáticamente en el dominio.
